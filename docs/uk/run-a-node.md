# Вузол для вашої громади

Вузол — це комп'ютер громади: він приймає учасників, веде ланцюжок кожного рахунку, ставить свій підпис на кожному
записі й публікує підписане зведення всього, що зберігає. Спершу прочитайте, [як це працює](how-it-works.md).

Завести вузол можна трьома способами: на це піде від хвилини до вечора. В усіх трьох працює той самий відкритий код.

Перш ніж запрошувати когось, кого ви не знаєте особисто: хто веде громаду, той відповідає за її учасників і за її
податки. З'ясуйте з юристом правову форму і правила щодо платіжних послуг у вашій країні
([відкриті питання](../../specs/mutual.md#questions-for-a-lawyer-and-a-tax-adviser), англійською).

## 1. Створити громаду на хабі — хвилина, без сервера

Хаб — це одне розгортання, на якому живуть вузли багатьох громад. Наш хаб публічний:

1. Відкрийте застосунок: https://okay-mutual.okay-effects.workers.dev/app/
2. Виберіть **Створити громаду**: її назва, її місце в адресі, її одиниця, як до неї вступають, кого приймають,
   ліміти новачка, її правила.
3. Це все. Ключ вашого пристрою відкрив власний рахунок громади: ви її засновник.
4. **Запросити** показує посилання. Хто його відкриє, той опиниться в застосунку у вашій громаді й зможе попросити
   про вступ.
5. **Громада** — це ваш кабінет: хто просить про вступ (прийняти з лімітами або відхилити), учасники, їхні ліміти.

Що тримаєте ви, а що хаб: ключ громади — той, яким приймають учасників і встановлюють ліміти, — лежить на вашому
пристрої й більше ніде. Власний ключ вузла, яким той ставить свій підпис на кожному записі, зберігає хаб. Тож
оператор хабу не може ні витрачати за когось, ні керувати вашою громадою, але міг би перестати її обслуговувати.
Застосунок кожного учасника весь час перевіряє вузол і показав би, якби записи змінили. Якщо цього замало, запустіть
власний хаб.

Публічний хаб обмежує, скільки громад можна створити з однієї адреси за день.

## 2. Власний хаб на Cloudflare — пів години, досить безплатного облікового запису

Потрібні обліковий запис Cloudflare, Java 21 або новіша, [sbt](https://www.scala-sbt.org/) і Node.js.

```sh
git clone https://github.com/okay-effects/okay-mutual && cd okay-mutual
printf 'CLOUDFLARE_API_TOKEN=…\nCLOUDFLARE_ACCOUNT_ID=…\n' > .env && chmod 600 .env
./worker/deploy.sh
```

Токен повинен мати дозвіл на редагування Workers. Скрипт збирає хаб і сайт та розгортає їх; він друкує вашу
адресу, `https://okay-mutual.<your-account>.workers.dev`. Відкрийте там `/app/` і створіть свою громаду.

Жодного секрету задавати не треба: пару ключів кожного вузла створюють разом із вузлом, усередині Cloudflare, і
вона ніколи його не залишає. Налаштування лежать у `worker/wrangler.toml`:

| Змінна | Значення | Типово |
|---|---|---|
| `HUB_OPEN` | `1`: створити громаду на вашому хабі може будь-хто; будь-що інше: лише той, хто має `HUB_TOKEN` | `1` |
| `HUB_PER_DAY` | скільки громад можна створити з однієї адреси за день | `3` |
| `HUB_MAX` | скільки громад може бути загалом | `500` |
| `HUB_PERSONAL` | які способи роботи з приватними особами може обрати громада тут: `business`, `earned`, `vouched`, `record`, `line` (через кому) | усі |
| `HUB_MAX_CREDIT` | найбільша кредитна лінія нового бізнесу, яку може задати громада, у сотих (0: будь-яка) | `0` |
| `HUB_MAX_PERSONAL` | скільки щонайбільше може бути винна приватна особа в будь-якій громаді тут, у сотих (0: скільки завгодно) | `0` |

Щоб залишити хаб лише для себе, задайте `HUB_OPEN = ""`, виконайте `npx wrangler secret put HUB_TOKEN` у `worker/`
і створюйте громади запитом, який містить заголовок `x-hub-token`.

## 3. На власній машині — усе у ваших руках

Потрібні Java 21 або новіша і sbt.

```sh
git clone https://github.com/okay-effects/okay-mutual && cd okay-mutual
sbt site host/assembly                       # the site with the app, and the hub's jar
java -jar target/okay-mutual-node.jar
```

Відкрийте http://127.0.0.1:8787/app/ і створіть громаду.

Усе, що знає хаб, — разом із ключем кожного вузла — лежить у `node-data/okay.sqlite`. Робіть резервні копії цього
каталогу і нікому його не давайте: хто його має, той може підписувати від імені ваших вузлів.

| Змінна | Значення | Типово |
|---|---|---|
| `NODE_DIR` | де зберігаються дані | `node-data` |
| `PORT`, `HOST` | де хаб слухає | `8787`, `127.0.0.1` |
| `HUB_OPEN`, `HUB_TOKEN`, `HUB_PER_DAY`, `HUB_MAX` | як вище | `1`, немає, `20`, `500` |
| `SITE` | каталог сайту, який віддає хаб | `target/site` |

Щоб до хабу могли дістатися інші, поставте його за вебсервером із HTTPS (ключам застосунку потрібна захищена
сторінка) і задайте `HOST=0.0.0.0` або налаштуйте проксі на нього.

## Хто керує громадою

Ніхто ззовні, і жодного пароля немає. Власний рахунок громади — такий самий рахунок, як і будь-який інший:
пристрої, чиї ключі мають право ним *керувати*, — це і є правління громади. У застосунку, коли вибрано цей рахунок:

- **Громада** — хто просить про вступ, учасники, сума всіх балансів (завжди нуль), ліміти кожного учасника.
- **Пристрої** — додати пристрій ще одного члена правління або прибрати якийсь. Це той самий екран, яким
  людина користується для свого телефона й ноутбука.

Команду вузлу (прийняти учасника, встановити ліміт) підписано таким ключем, вона чинна десять хвилин і приймається
один раз.

### Якщо ключі керівників втрачено

Громадою керують ключі, які тримають її власний рахунок. **Додайте другого керівника першого ж дня** — інший свій
пристрій або людину, якій довіряєте (*Громада → Керівники*); офіс попереджає, доки керівник один.

Якщо всі такі ключі все ж утрачено, учасники можуть обрати нового керівника — там, де громада сама приймає
учасників. Учасник відкриває *Перевірити вузол → Обрати керівника* і називає ключ пристрою; коли більше половини
тих, хто є учасником щонайменше місяць, назвуть той самий ключ, вузол оголошує його в ланцюжку самої громади.
Після строку очікування, прийнятого в громаді, цей ключ керує — якщо за цей час керівник, у якого ключ іще
цілий, не скаже «ні».

Там, де вступити може будь-хто, таких виборів немає: будь-хто міг би проголосувати за себе. Там єдиний захист —
два керівники.

## Чого ще немає

- Лінії довіри поєднують дві громади, кожна з яких відкрила лінію до іншої (**Громада**, далі
  **Лінії довіри**), в одній і тій самій одиниці. Поки що немає: платежу через третю громаду та ліній між різними
  одиницями.
- Перенесення громади з одного хабу на інший разом з її історією.
- Спільний рахунок, тримач якого — інший спільний рахунок; повернення позиченої лінії.
- Умови користування для оператора хабу; резервні копії, крім тих, що дає платформа або ваші власні копії.
