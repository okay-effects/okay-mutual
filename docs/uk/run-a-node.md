# Як запустити вузол

Вузол — це комп'ютер громади: він приймає учасників, веде ланцюжок кожного рахунку, ставить свій підпис на кожному
записі й публікує підписане зведення всього, що зберігає. Запустити його може будь-хто. Спершу прочитайте,
[як це працює](how-it-works.md).

Перш ніж запрошувати когось, кого ви не знаєте особисто: оператор вузла відповідає за його учасників і за його
податки. З'ясуйте з юристом правову форму і правила щодо платіжних послуг у вашій країні
([відкриті питання](../../specs/mutual.md#questions-for-a-lawyer-and-a-tax-adviser), англійською).

## На одній машині

Потрібна Java 21 або новіша і [sbt](https://www.scala-sbt.org/).

```sh
git clone https://github.com/okay-effects/okay-mutual && cd okay-mutual
sbt site host/assembly                       # the site with the wallet, and the node's jar
NODE_NAME="Our Town" JOIN=open DEFAULT_CREDIT=10000 DEFAULT_CEILING=30000 java -jar target/okay-mutual-node.jar
```

Відкрийте http://127.0.0.1:8787/wallet/ — це гаманець, який спілкується з вашим вузлом.

Під час першого запуску в `node-data/` з'являються два файли, які можете читати лише ви:

- `node.key` — ключ вузла. Хто його має, той може підписувати від імені вашого вузла. Зробіть резервну копію
  і нікому його не давайте.
- `setup.token` — друкується один раз, під час першого запуску. У гаманці виберіть **Заснувати цю громаду** і введіть
  його: так відкривається власний рахунок громади з ключем вашого пристрою.
  Після цього токен уже нічого не відкриває.

Усе, що знає вузол, лежить у `node-data/okay.sqlite`. Робіть резервні копії цього каталогу.

| Змінна | Значення | Типово |
|---|---|---|
| `NODE_NAME` | назва громади, як її показують гаманці | `A community` |
| `NODE_UNIT` | назва одиниці; одиниця рахується як одна одиниця національної валюти | `PLN` |
| `JOIN` | `open`: рахунок може відкрити будь-хто; будь-що інше: лише ті, кого ви приймете | лише прийняті |
| `DEFAULT_CREDIT`, `DEFAULT_CEILING` | межі нового учасника, у сотих частках (`10000` — це 100.00) | `0` |
| `NODE_DIR` | де зберігаються дані | `node-data` |
| `PORT`, `HOST` | де вузол слухає | `8787`, `127.0.0.1` |
| `SITE` | каталог сайту, який віддає вузол | `target/site` |

Щоб до вузла могли дістатися інші, поставте його за вебсервером із HTTPS (ключам гаманця потрібна захищена
сторінка) і задайте `HOST=0.0.0.0` або налаштуйте проксі на нього.

## Хто керує вузлом

Ніхто ззовні, і жодного пароля немає. Власний рахунок громади — такий самий рахунок, як і будь-який інший:
пристрої, чиї ключі мають право ним *керувати*, — це і є правління громади. У гаманці, коли вибрано цей рахунок:

- **Громада** — учасники, сума всіх балансів (завжди нуль) і межі кожного учасника, які тут можна
  встановити.
- **Пристрої** — додати пристрій ще одного члена правління або прибрати якийсь. Це той самий екран, яким
  людина користується для свого телефона й ноутбука.

Команду вузлу (наприклад, встановити межу) підписано таким ключем, вона чинна десять хвилин і приймається один раз.

Там, де вступ не відкритий, учасника приймають командою члена правління, до якої додано перший запис новачка,
підписаний ним самим. Екрана для цього в гаманці ще немає.

## Чого ще немає

- Лінії довіри до інших вузлів: спроєктовано ([протокол](../../specs/protocol.md), англійською), не збудовано.
  Сьогодні вузол — це одна громада.
- Точка входу для Cloudflare Worker: код вузла там працює (його перевірено на такій самій хмарі в пам'яті), але
  пакування ще не написано.
- Родинні рахунки й рахунки компаній, тримачами яких є інші рахунки; два підписи; відновлення втраченого ключа
  вузлом.
- Резервні копії, крім копіювання каталогу; обмеження частоти відкриття рахунків там, де вступ відкритий.
