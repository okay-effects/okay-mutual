# Узел для вашей общины

Узел — это компьютер общины: он принимает участников, хранит цепочку каждого счёта, ставит вторую подпись на
каждой записи и публикует подписанную сводку всего, что у него хранится. Сначала прочитайте,
[как это устроено](how-it-works.md).

Завести узел можно тремя способами: от минуты до вечера. Во всех трёх работает один и тот же открытый код.

Прежде чем приглашать тех, кого вы не знаете лично: тот, кто ведёт общину, отвечает за её участников и за её
налоги. Правовую форму и правила о платёжных услугах в вашей стране выясните с юристом
([открытые вопросы](../../specs/mutual.md#questions-for-a-lawyer-and-a-tax-adviser), на английском).

## 1. Создать общину на хабе — минута, сервер не нужен

Хаб — это одна установка, на которой живут узлы многих общин. Наш хаб открыт для всех:

1. Откройте кошелёк: https://okay-mutual.okay-effects.workers.dev/wallet/
2. Выберите **Создать общину**: её название, её место в адресе, её единица, как в неё вступают, лимиты новичка.
3. Это всё. Ключ вашего устройства открыл собственный счёт общины: вы её основатель.
4. **Пригласить** показывает ссылку. Тот, кто её откроет, попадёт в кошелёк уже в вашей общине и сможет
   попросить о вступлении.
5. **Община** — ваш кабинет: кто просит о вступлении (принять с лимитами или отказать), участники, их лимиты.

Что хранится у вас и что у хаба: ключ общины — тот, которым принимают участников и задают лимиты, — лежит на
вашем устройстве и больше нигде. Собственный ключ узла, которым ставится вторая подпись на каждой записи, хранит
хаб. Поэтому оператор хаба не может тратить за кого-либо или управлять вашей общиной, но мог бы перестать её
обслуживать. Кошелёк каждого участника постоянно проверяет узел и показал бы, если бы записи изменили. Если
этого мало, заведите собственный хаб.

Открытый хаб ограничивает, сколько общин можно создать с одного адреса за день.

## 2. Собственный хаб на Cloudflare — полчаса, хватит бесплатной учётной записи

Нужны учётная запись Cloudflare, Java 21 или новее, [sbt](https://www.scala-sbt.org/) и Node.js.

```sh
git clone https://github.com/okay-effects/okay-mutual && cd okay-mutual
printf 'CLOUDFLARE_API_TOKEN=…\nCLOUDFLARE_ACCOUNT_ID=…\n' > .env && chmod 600 .env
./worker/deploy.sh
```

Токену нужно право редактировать Workers. Скрипт собирает хаб и сайт и разворачивает их; он печатает ваш адрес,
`https://okay-mutual.<your-account>.workers.dev`. Откройте там `/wallet/` и создайте свою общину.

Никакого секрета задавать не нужно: пара ключей каждого узла создаётся вместе с узлом, внутри Cloudflare, и
никогда его не покидает. Настройки лежат в `worker/wrangler.toml`:

| Переменная | Значение | По умолчанию |
|---|---|---|
| `HUB_OPEN` | `1`: создать общину на вашем хабе может кто угодно; любое другое значение: только тот, у кого есть `HUB_TOKEN` | `1` |
| `HUB_PER_DAY` | сколько общин можно создать с одного адреса за день | `3` |
| `HUB_MAX` | сколько общин может быть всего | `500` |

Чтобы оставить хаб только себе, задайте `HUB_OPEN = ""`, выполните `npx wrangler secret put HUB_TOKEN` в `worker/`
и создавайте общины запросом с заголовком `x-hub-token`.

## 3. На своей машине — всё в ваших руках

Нужны Java 21 или новее и sbt.

```sh
git clone https://github.com/okay-effects/okay-mutual && cd okay-mutual
sbt site host/assembly                       # the site with the wallet, and the hub's jar
java -jar target/okay-mutual-node.jar
```

Откройте http://127.0.0.1:8787/wallet/ и создайте общину.

Всё, что знает хаб, — включая ключ каждого узла — лежит в `node-data/okay.sqlite`. Делайте резервную копию
каталога и никому его не давайте: тот, у кого он есть, может подписывать от имени ваших узлов.

| Переменная | Значение | По умолчанию |
|---|---|---|
| `NODE_DIR` | где хранятся данные | `node-data` |
| `PORT`, `HOST` | где он принимает соединения | `8787`, `127.0.0.1` |
| `HUB_OPEN`, `HUB_TOKEN`, `HUB_PER_DAY`, `HUB_MAX` | как выше | `1`, нет, `20`, `500` |
| `SITE` | каталог сайта, который он отдаёт | `target/site` |

Чтобы он был доступен другим, поставьте его за веб-сервером с HTTPS (ключам кошелька нужна защищённая страница) и
задайте `HOST=0.0.0.0` или направьте на него запросы через прокси.

## Кто управляет общиной

Никто извне, и никакого пароля нет. Собственный счёт общины — такой же счёт, как любой другой: устройства, ключи
которых могут им *управлять*, и есть правление общины. В кошельке, когда выбран этот счёт:

- **Община** — кто просит о вступлении, участники, сумма всех балансов (всегда ноль), лимиты каждого участника.
- **Устройства** — добавить устройство ещё одного члена правления или убрать одно из них. Это тот же экран,
  которым человек пользуется для своего телефона и ноутбука.

Команда узлу (принять участника, задать лимит) подписывается таким ключом, действует десять минут и принимается
один раз.

## Чего пока нет

- Линии доверия соединяют две общины, каждая из которых открыла линию к другой (**Община**, затем
  **Линии доверия**), в одной и той же единице. Пока нет: платежа через третью общину и линий между разными
  единицами.
- Перенос общины с одного хаба на другой вместе с её историей.
- Семейные счета и счета компаний, держателями которых выступают другие счета; две подписи; восстановление
  потерянного ключа узлом.
- Условия использования для оператора хаба; резервные копии сверх того, что даёт платформа или ваши собственные
  копии.
