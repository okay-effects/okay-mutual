# Запустить узел

Узел — это компьютер общины: он принимает участников, хранит цепочку каждого счёта, ставит вторую подпись на каждой
записи и публикует подписанную сводку всего, что у него хранится. Запустить узел может каждый. Сначала прочитайте,
[как это устроено](how-it-works.md).

Прежде чем приглашать тех, кого вы не знаете лично: оператор узла отвечает за его участников и за его налоги.
Правовую форму и правила о платёжных услугах в вашей стране выясните с юристом
([открытые вопросы](../../specs/mutual.md#questions-for-a-lawyer-and-a-tax-adviser), на английском).

## На одной машине

Нужны Java 21 или новее и [sbt](https://www.scala-sbt.org/).

```sh
git clone https://github.com/okay-effects/okay-mutual && cd okay-mutual
sbt site host/assembly                       # the site with the wallet, and the node's jar
NODE_NAME="Our Town" JOIN=open DEFAULT_CREDIT=10000 DEFAULT_CEILING=30000 java -jar target/okay-mutual-node.jar
```

Откройте http://127.0.0.1:8787/wallet/ — это кошелёк, который говорит с вашим узлом.

При первом запуске в `node-data/` появляются два файла, читать которые можете только вы:

- `node.key` — ключ узла. Тот, у кого он есть, может подписывать от имени вашего узла. Сделайте резервную копию;
  никому его не передавайте.
- `setup.token` — печатается один раз при первом запуске. В кошельке выберите **Основать эту общину** и введите его:
  так открывается собственный счёт общины с ключом вашего устройства. После этого токен
  уже ничего не открывает.

Всё, что знает узел, лежит в `node-data/okay.sqlite`. Делайте резервную копию всего каталога.

| Переменная | Значение | По умолчанию |
|---|---|---|
| `NODE_NAME` | название общины, как его показывают кошельки | `A community` |
| `NODE_UNIT` | название единицы; единица считается за одну единицу национальной валюты | `PLN` |
| `JOIN` | `open`: счёт может открыть кто угодно; любое другое значение: только те, кого вы приняли | только принятые |
| `DEFAULT_CREDIT`, `DEFAULT_CEILING` | пределы нового участника, в сотых долях (`10000` — это 100.00) | `0` |
| `NODE_DIR` | где хранятся данные | `node-data` |
| `PORT`, `HOST` | где узел принимает соединения | `8787`, `127.0.0.1` |
| `SITE` | каталог сайта, который узел отдаёт | `target/site` |

Чтобы узел был доступен другим, поставьте его за веб-сервером с HTTPS (ключам кошелька нужна защищённая страница) и
задайте `HOST=0.0.0.0` или направьте на него запросы через прокси.

## Кто управляет узлом

Никто извне, и никакого пароля нет. Собственный счёт общины — такой же счёт, как любой другой: устройства, ключи
которых могут им *управлять*, и есть правление общины. В кошельке, когда выбран этот счёт:

- **Община** — участники, сумма всех балансов (всегда ноль) и пределы каждого участника, которые можно
  задать.
- **Устройства** — добавить устройство ещё одного члена правления или убрать одно из них. Это тот же
  экран, которым человек пользуется для своего телефона и ноутбука.

Команда узлу (например, задать предел) подписывается таким ключом, действует десять минут и принимается один раз.

Там, где вступление не открыто, участника принимают командой члена правления, к которой приложена первая запись
новичка, подписанная им самим. Экрана для этого в кошельке пока нет.

## Чего пока нет

- Линии доверия с другими узлами: спроектированы ([протокол](../../specs/protocol.md), на английском), не
  построены. Сегодня узел — это одна община.
- Точка входа для Cloudflare Worker: код узла там работает (он проверен тестами на таком же облаке в памяти), но
  упаковка не написана.
- Семейные счета и счета компаний, держателями которых выступают другие счета; две подписи; восстановление
  потерянного ключа узлом.
- Резервные копии, кроме копирования каталога; ограничение частоты открытия счетов там, где вступление открыто.
